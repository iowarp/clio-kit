20 skills. Each was given one realistic task with only its own
plugin loaded and only the MCP servers its frontmatter declares.

Whether the skill fired, and whether the tool sequence was right, is
what judges the skill. A failed tool call usually judges the server or
the environment instead -- but not always: a server correctly refusing
a path the agent guessed on its way to the right one is a working
server, so read a failure with its sequence rather than as a count.

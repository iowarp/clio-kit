CLIO Kit 2.11.1 updates the locked runtimes used by the 2.11 meta-marketplace and
its scientific MCP servers.

## Fixed

Locked runtime dependencies advance to the patched versions reported by the
current dependency audit, including FastMCP and OpenTelemetry API.
The maintained MCP servers receive new immutable patch versions for these
dependency updates. Their tool schemas retain the 2.11.0 contracts.

See the [CHANGELOG](https://github.com/iowarp/clio-kit/blob/v2.11.1/CHANGELOG.md)
for the meta-marketplace and selective-installation capabilities in 2.11.

CLIO Kit 2.12.7 republishes every MCP server with a fix for a denial of service
in opentelemetry-api. It also installs adios2 from wheels on macOS, stops hdf5
from writing outside its granted cache directory, and runs every Python MCP
server on Python 3.12. Every server has a new patch version.

2.12.6 was tagged but never published, so 2.12.7 is the first release with
these changes.

## Security

- Every server, the launcher and clio-agentic-search lock opentelemetry-api
  1.45.2, which fixes quadratic-time `traceparent` parsing
  (CVE-2026-126360, GHSA-mf5v-w3w3-f6cg).

## Fixed

- adios (2.3.2) and paraview (2.2.8) require adios2 2.13.0.1001 or later,
  the first release with macOS wheels, so their first prepare on a Mac no
  longer builds adios2 from source. Windows still skips adios2 (#417).
- hdf5 (2.3.1) no longer creates `~/.hdf5_mcp` at import. It saves metrics
  under the server's granted cache directory and creates that directory only
  when it first writes to it (#418).
- Every Python server pins Python 3.12 through `.python-version`, so uv never
  picks a newer interpreter that would force dependencies to build from
  source (#419).
- Building clio-kit from source on Windows no longer fails with a cp1252
  `UnicodeDecodeError`: the build hook reads component sources as UTF-8
  (#421).

See the [CHANGELOG](https://github.com/iowarp/clio-kit/blob/v2.12.7/CHANGELOG.md)
for details.

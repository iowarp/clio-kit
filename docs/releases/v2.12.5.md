CLIO Kit 2.12.5 stops the adios MCP server from compiling adios2 on Windows.
adios is the only MCP server with a new version (2.3.1).

2.12.4 was tagged but never published, so 2.12.5 is the first release with
this change.

## Fixed

- adios2 publishes no Windows wheels, so the first `clio-kit mcp-server
  --prepare adios` on Windows built it from source: about 7.5 minutes on a
  cold cache with MSVC installed, a failure without it, and a package that
  never imported. adios2 is now skipped on Windows, and that prepare finishes
  in seconds. The server and `list_bp5` work on Windows; the tools that read
  BP5 contents report "ADIOS2 bindings aren't available on Windows" through a
  typed `Adios2Unavailable` error (reason `adios2_unavailable`) (#413).

See the [CHANGELOG](https://github.com/iowarp/clio-kit/blob/v2.12.5/CHANGELOG.md)
for details.

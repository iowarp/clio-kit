CLIO Kit 2.12.1 makes the MCP server launcher recover from a half-built
server environment, adds a command that builds a server's environment without
starting it, and points the ndp server at the public NDP catalog. ndp is the
only MCP server with a new version (2.2.8).

## Added

- `clio-kit mcp-server --prepare <server>` builds or syncs a server's
  environment, skips the launch, and reports one JSON result line with a typed
  exit code. It is safe to repeat.

## Fixed

- A Python server environment that an interrupted or denied first build left
  without an interpreter is set aside and rebuilt on the next launch, instead
  of failing every later start. New environments are created in a temporary
  sibling directory and renamed into place, and concurrent launches of one
  server wait for a single build.
- ndp 2.2.8 works with no configuration: it searches the public NDP catalog at
  `https://nationaldataplatform.org/catalog` instead of a retired endpoint.
  Set `NDP_CATALOG_URL` to use another catalog, or `NDP_API_URL` to use a
  self-hosted NDP Endpoint API, which also serves the `local` and `pre_ckan`
  catalogs. Connection errors name the URL and the variable to change.

See the [CHANGELOG](https://github.com/iowarp/clio-kit/blob/v2.12.1/CHANGELOG.md)

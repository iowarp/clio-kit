CLIO Kit 2.12.0 improves five scientific MCP servers after running them
through a coding agent on planted datasets, and patches every other server for
updated locked dependencies.

## Added

- adios 2.3.0: `variable_stats` for per-step statistics with extreme locations,
  and sliced, size-capped `read_variable_at_step`.
- hdf5 2.3.0: axis profiles in `hdf5_aggregate_stats` and a one-call structure
  walk in `visit`.
- pandas 2.4.0: read-only inline `aggregate` with date buckets, plus outlier
  rows in `profile_data` and offending rows in `validate_data`.
- parquet 2.3.0: grouped, multi-operation `aggregate_column` and per-column
  null counts.
- slurm 3.1.0: default partition, real job reasons and partition hints
  (contract `clio-kit-slurm-user-v3.1`).

## Fixed

Every other server takes a patch release for the joserfc 1.7.7 and pyasn1
0.6.5 lock updates; web 2.1.5 also declares `openWorldHint`.

See the [CHANGELOG](https://github.com/iowarp/clio-kit/blob/v2.12.0/CHANGELOG.md)
for per-server details.
